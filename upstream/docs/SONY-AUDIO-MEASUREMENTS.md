# Sony 三项音效的实际输出测量

## 2026-10-09：真实音乐的时间—频率图与持续处理

按用户的新示例，从授权曲库只读解码同一首 44.1 kHz／16 bit／双声道 ALAC 的前 60 秒，测试三项效果的全部 **8 种开关组合**。DC 使用 Type A / Standard（2），黑胶使用 Standard（1），DSEE 使用播放器既有原配置；没有用另一个 DSEE 参数冒充 DMP-Z1 整机调音。原十个 Sony 文件、C++ 指令图和同一 DSP DLL 均先核查。

| 配置 | 输出采样率 | 60 秒处理耗时 | 相对实时速度 | 首个 0.5 秒缓冲 |
| --- | ---: | ---: | ---: | ---: |
| 仅 DSEE AI | 176.4 kHz | 7.787 秒 | 7.71 倍 | 342 ms |
| 仅 DC 相位线性器 | 44.1 kHz | 1.734 秒 | 34.60 倍 | 302 ms |
| 仅黑胶 | 44.1 kHz | 2.032 秒 | 29.53 倍 | 287 ms |
| DSEE + DC | 176.4 kHz | 6.853 秒 | 8.76 倍 | 485 ms |
| DSEE + 黑胶 | 176.4 kHz | 7.088 秒 | 8.46 倍 | 491 ms |
| DC + 黑胶 | 44.1 kHz | 1.972 秒 | 30.42 倍 | 440 ms |
| 三项全部开启 | 176.4 kHz | 7.285 秒 | 8.24 倍 | 530 ms |

首缓冲包含进程启动与初始化，是音效流水线产出时间，不含 DAC 或播放器的设备启播延迟。多阶段最多使用三个工作进程；同一 60 秒输入的串行和三进程全开输出完全一致。所有输出帧数、时长匹配，样本均有限，源文件未改动。另对这段真实音乐的每种组合取 5 秒，以原版 ARM 为参考检查完整 PCM 和所有已分配内部状态，**8／8 组逐位一致**；不是用频谱看起来相似代替原版对照。更广的 [336 组 ARM／x86 对照](SONY-X86-VERIFICATION.json)覆盖全部 DC／黑胶档位、采样率及研究参数。

本机图表位于 `release/sony-spectrum/sony-spectrogram-all-on-vs-off.png` 和 `sony-spectrogram-eight-combinations.png`，同名 PDF 可导出。音乐、音频片段、音频指纹和音乐导出的图像不进入 Git、EXE 或固件研究副本；源码仅保留匿名的 [测量汇总与方法](SONY-SPECTROGRAM-VERIFICATION.json)。

图表采用黑底时间—频率显示，频率 0–24 kHz、时间 0–60 秒；左右声道按功率平均。Hann 窗重叠 75%，44.1 kHz 为 4,096 点、176.4 kHz 为 16,384 点，窗口时长均约 0.09288 秒、频率分辨率均约 10.7666 Hz。每张图共用 **−120～0 dBFS／频率 bin** 的绝对标尺，不对各图分别归一化。44.1 kHz 的图在 22.05 kHz 以上标注无数据；DSEE 的高频为处理器真实输出。

该测量发生在原生解码和 Sony DSP 输出端、音频设备之前。幅度频谱不能完整反映相位线性器，其相位／脉冲和声道隔离另见下文。高频能量增加不能独立证明音质更好，亦不能将非 Hi-Res 源文件变为原始 Hi-Res。**本图与实时结果不包含尚未移植的 DSD Remaster、DMP-Z1 整机 DAC／模拟音色**；相关硬件边界见 [研究记录](DMP-Z1-RESEARCH.md)。

另做 [82 组持续处理测试](SONY-REALTIME-VERIFICATION.json)，每组 30 秒生成的双声道多音信号。44.1／48 kHz 各覆盖 DSEE 开启时六种 DC × 四种黑胶的全部 24 个组合；192 kHz 覆盖六种 DC、四种黑胶单项及全部 24 个组合，DSEE 通过播放器相同的计划旁路。82／82 通过，最慢约 6.60 倍实时；每组输出帧数、采样率、有限峰值均核对。运行 `npm run check:sony:realtime` 可重新测本机性能。该基准不包含解码、设备延迟和真实设备的长期稳定性。

## 2026-10-08：早期十秒平均频谱测量

本轮使用同一段十秒无损 ALAC 的原生解码结果，分别生成全部关闭、全部开启，以及只开 DSEE AI、只开 DC 相位线性器、只开黑胶处理器的输出。开启参数为 DSEE AI、DC Type A / Standard（2）、Vinyl Standard（1）。实际执行固定哈希的 Sony 原模型与 x86 C++ 转写内核；九个原文件和编译 DLL 均先校验。

音乐与生成的 WAV 留在忽略的本机验证目录，不进入源码、EXE 或固件研究副本。用户要求的音乐频谱图以 PNG／PDF 保存在本机 `release/sony-spectrum/`；该目录不进入 Git。以下只记录方法和汇总数值，文档图片使用合成脉冲。

### 全开与全关

原始输入为 44.1 kHz、双声道、441,000 帧；三项全开后为 176.4 kHz、1,764,000 帧，时长仍为十秒。本次三个工作进程处理约 1.40 秒；只开 DSEE 约 1.30 秒，只开相位约 0.29 秒，只开黑胶约 0.34 秒。耗时来自这一片段和这台主机，不代表所有曲目的固定性能。

频谱使用 Hann 窗的 Welch 平均功率谱密度：窗口时长约 0.18576 秒、重叠 50%，44.1 kHz 使用 8,192 点，176.4 kHz 使用 32,768 点，频率分辨率相同。排除开头一秒及结尾半秒，先对左右声道功率求平均，使用同一绝对 dBFS/Hz 标尺；没有把每条曲线分别归一化或拉到相同峰值。全关文件在 22.05 kHz 以上没有可表示的频谱，图中不虚构这些数据。

| 输出 | 采样率 | 峰值，满刻度为 1 | RMS |
| --- | ---: | ---: | ---: |
| 全部关闭 | 44.1 kHz | 0.624939 | 0.058538 |
| 三项全开 | 176.4 kHz | 0.637778 | 0.059992 |
| 仅 DSEE AI | 176.4 kHz | 0.631260 | 0.058658 |
| 仅相位模式 2 | 44.1 kHz | 0.623828 | 0.059402 |
| 仅黑胶模式 1 | 44.1 kHz | 0.624458 | 0.059063 |

所有输出均为有限浮点样本，帧数和时长匹配。相位及黑胶各自与全关输出逐样本相减的 RMS 分别为 0.002476、0.003655，说明它们确实改变了实际输出。全开与单项频谱也有相应差异；高频能量增加本身不能证明音质更好，也不能证明源文件是 Hi-Res。

### 相位测量

相位器不能只用平均幅度频谱判断。另生成 65,536 帧、44.1 kHz 双声道脉冲，第 512 帧左声道为 0.25、右声道为 -0.125，其余为零；测量模式 2 输出与原脉冲 FFT 的比值。20 Hz–20 kHz 内最大幅度变化约 0.467 dB、最大相位变化约 9.030°；中高频趋近零。

![原版相位器的合成脉冲幅度和相位响应](media/v0.3.0/sony/sony-dc-phase-response.png)

测量发生在解码／音效输出端、进入音频设备之前，未包含 Windows 混音器、DAC 或模拟耳机输出。相位器左右独立历史的隔离另有 [24 组原单声道对照](SONY-PHASE-VERIFICATION.json)，本次 EXE 自检重新运行了该检查。

### 原版执行证据与适用输入

频谱作为输出变化的证据，结合当时的 246 组 PCM 和内部状态逐位对照及固定原组件哈希判断原版算法确实执行；[最新对照](SONY-X86-VERIFICATION.json)已扩展为 336 组。本次测量使用的 `sony-dsp-x86.dll` SHA-256 为 `f5aa02c1dd93e209c88080a96b4ec141a2cf27fc382b613d4600b0d94c43e4db`，与上述 ARM 对照时相同。

DSEE 原版支持 44.1／48 kHz 输入；192 kHz 原音源旁路这一项，继续保留原采样率并执行支持该采样率的 DC／黑胶。原生 DSD 和 DoP 旁路这三项；DSD 转 PCM 后可以处理。界面的技术标志按照当前实际处理链显示，不能把设定开关等同于所有输入下都生效。
