## 修复行为与原因

- 播放条原先复用了同一个 SVG 缓存键，播放状态改变后仍使用首个几何图形。现在顶部与玻璃播放按钮共用 220ms 线性几何变化，三角形连续变成双暂停条；中途反向切换保留当前形状，减少动态效果直接呈现正确状态。
- 循环和播放定位按钮原先触发了详情的焦点自动滚动。现在只有滚动区域内的控件执行自动滚动；底部玻璃按钮不再推移详情。播放定位仍沿原曲目定位与高亮流程运行。
- 滚动上限原先在绘制后修正。现在在输入和绘制前测量、限制滚动范围；真实滚动条支持拖动和点击轨道，触摸及滚轮继续使用同一范围，窗口缩放也先限制再绘制。
- Windows GDI 的光标会被 D3D 翻转呈现覆盖。现在 Windows EDIT 继续处理文字、焦点、选区、剪贴板、输入法和插入位置，画面将其文字表面与实际位置光标一同合成；闪烁周期读取系统设置。字体与控件表面缓存复用，只有输入、选区、滚动、主题或尺寸变化才重新上传。
- 修正单行 EDIT 在合成绘制中丢失文字的问题，单行使用真实原生字体和字符位置绘制。FTP 与在线服务的两个密码框均使用 `*`，聚焦和失焦共用相同文字表面；输入值保持原内容，诊断不记录密码文本。
- 搜索加载官方离线 OpenCC 1.4.2 字表及 pinyin-pro 3.29.5。简繁体双向匹配，支持无声调全拼、空格分隔拼音、首字母、大小写与常见多音字；查询和标题共用字符归一化，原始名称、文件标签、保存索引和播放定位 ID 不改写。许可及来源随运行库附带，搜索时无需联网。
- 按用户在本轮的追加要求，移除音乐专辑的独立“360° 查看专辑模型”入口，并拒绝该音乐场景的旧打开命令。此次删除范围为音乐专辑独立查看；主专辑架与详情的三维渲染、玻璃、封面动画及原档案界面继续使用原有路径。
- 所有曲目格式标签去掉多余的小箭头；CD-DA 与其他格式共用同一纯文字绘制。
- 插盘广播立即触发只读检测，轮询作为补充。新识别的 Audio CD 在专辑选择界面自动定位一次，正在使用详情或面板时延后；不自动播放或打开专辑，重复检测不抢回用户选择。标识与顶部导航之间使用官方 Tabler SVG 线性旋转提示读取，昼夜共用 currentColor。
- 光盘使用带中心孔、金属环与沟槽的透明圆形封面。仅该光盘实际播放时每秒转四圈，暂停保留当前角度，停止或播放其他专辑时保持静止；减少动态效果时静止，歌曲仍正常播放。
- SSR 光盘材质根据光源、视角及径向沟槽计算可见光衍射彩虹，并接入已有屏幕空间反射。RTX 使用硬件 DXR 光线查询，光盘边缘与中心孔正确参与光线命中，反射与光子路径加入光盘光栅的波长分离。关闭反射时保持银色；彩虹的位置和强度随视角变化。新材质仅作用于光盘，常规专辑继续使用原玻璃与封面路径。
- 独占输出失败时显示实际设备、源采样率／声道及设备支持的速率。设置的 Windows 默认输出同时显示真实设备名称。本机默认是 MSI MP252L 的 HDMI 音频，独占仅支持 48 kHz，44.1 kHz 的 CD 因此被驱动拒绝；选择已连接的 FiiO Q1 后支持 44.1 kHz。没有悄悄重采样、切为共享输出或改写用户的设备选择。
