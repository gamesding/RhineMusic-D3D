# 原版功能对照与验收范围

本次将 V0.3.0 私有 Windows 增强副本迁移到原生 Direct3D 前端。原项目只读快照在 `upstream/`，其 SHA-256 清单是对照基准。下表区分“已有实现”“自动化／本机实测”和“仍待验证”，不把检测到设备等同于全部功能已实测，也不把画面截图等同于像素一致。

本次用户追加的控件更新：玻璃播放条中的三种循环模式及保存；全部编辑框的焦点边框与标准闪烁光标；设置下拉菜单的线性展开／收起／选中行动画；昼夜 Esc 键帽；首行 GamesDing GitHub 链接；暂时隐藏空在线入口；新增真实 WASAPI 独占及设备选择。循环扩展在原版播放器的自然结束边界执行，独占扩展复用原解码器；Sony 原文件与原 ASIO 路径保留。新控件的原生交互、FiiO 独占和自然结束循环证据另见 `build/controls-validation.json`、`build/wasapi-exclusive.json`、`build/repeat-playback.json`。

后续追加的手柄选歌：×／A 打开专辑，上下选歌、再次确认播放；进入动画中的方向输入保留，长歌单自动滚动，设置关闭后恢复选中行。设置输入框中的确认和左右方向不穿透到背后的专辑。PS4／PS5 触摸板左／右短按切到上一曲／下一曲，500ms 长按约 10 倍定位，中间按下播放／暂停；左短按在播放超过 3 秒后仍切到上一曲。失焦、断连和重连持有状态通过独立输入测试。官方 Kenney CC0 的 59 个 SVG 覆盖 PS4／PS5 面键、方向键、左右摇杆与触摸板，以及 Xbox ABXY，昼夜主题和对应操作说明纳入回归。用户另在可见隔离窗口完成 PS4 选歌和触摸板操作，记录 155 次真实输入并确认正常；自动命令检查与该实机记录分开保存，分别见 `build/controller-validation.json` 与 `build/physical-controller/physical-validation.json`。

CD 专辑右下角增加“弹出”及图标，□／X 在该上下文弹出光盘，触摸板中间仍播放／暂停；实际 F: 光驱弹出和 PS4 短震由用户确认正常。用户要求提高力度后，Sony 双电机改为 160／104，XInput 改为 42000／26000，仍保持 160ms。失焦或最小化时也处理震动归零。底部专辑序号、导航与类型提示避开播放玻璃；原版 ICO 的六个分辨率逐字节内置于原生程序和单文件 EXE。

全部临时提示共用 DirectWrite 的同一份测量／绘制排版，宽度根据文字和窗口调整，长文字、显式换行与连续路径自动换行，高度随内容增长。超过窗口高度的诊断可滚轮或触摸拖动阅读全文，阅读时暂停消失倒计时；提示避开底部播放和导航。
