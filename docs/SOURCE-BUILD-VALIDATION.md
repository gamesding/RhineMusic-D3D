# 私有源码副本构建与验证记录

日期：2026-10-11。此记录对应当前 Direct3D 源码发行工程，不用历史文档中的结果代替本次验证。

## 实际构建

完成两次完整 Release 构建与 EXE 打包：

1. 用户指定的源码目录，从空 CMake 构建目录配置、编译全部目标，编译着色器并生成单文件 EXE。
2. 按 Git 可提交文件集合制作干净副本，放在 **中文且含空格**的路径。副本没有旧的 build、预编译着色器、生成音频宿主 / 资源清单和任何上游 node_modules，依靠发行依赖恢复并再次从空构建目录成功生成 EXE。

使用 Windows x64、MSVC 19.44 / VS 2022 v143、Windows SDK 10.0.26100.0、CMake 4.3.3 和 Python 3.14.7。运行渲染验证的显卡为 NVIDIA RTX A4500，DXR 1.2。

干净构建实际发现并修复了两项可迁移性问题：为资源脚本指定 UTF-8，解决中文路径下 ICO 的 RC 编译失败；为 esbuild 明确设置随包离线依赖目录，消除对上游 node_modules 的依赖。构建脚本也不再硬编码工程盘符、Visual Studio Professional 或 FXC 的版本目录。

两个构建副本的 95 个原生源码、着色器源码和测试文件逐文件一致。重复编译的 PE / 音频清单可能因构建标记不同而改变哈希，不能据此承诺字节级可复现二进制；程序包校验清单分别记录各自的真实产物。

## Sony 手柄二进制边界

公共工程通过项目自有 C ABI 动态加载 `runtime/drivers/rhine-pad-bridge.dll`。公开 C++ / CMake 编译路径不包含 Sony SDK 私有头文件或静态库；编译日志 / 依赖文件未引用私有 SDK 安装目录。DLL 仅导出 7 个项目自有接口：版本、初始化、打开、读取、关闭、震动和终止。

- x64 DLL：244736 字节。
- SHA-256：`0c4eb4731d3d93838daa32d46bf30cc6ca9ea65c769fc2766d025c18e6c17aea`。
- 保留原 Sony 控制器库许可 PDF。
- 底层实现源码、SDK 头文件、SDK 静态库、示例与调试符号均不在发行目录。
- 项目导航、触摸板分区、长按定位、焦点、按键提示与震动时长逻辑仍以源码提供。

## 硬件与适用范围

本次设备探测读到了真实音频 CD 的一个 2352 字节扇区，读取样本没有保存。FiiO DAC 已连接；本轮源码整理没有重复全套 DAC / DSD 设备试验。旧版中的真实 PS4 选歌、触摸板、CD 弹出与震动经过使用者确认，但本次 PS4 不再连接，因此新 DLL 本轮只验证初始化和软件 / 界面路径。

真实 DualSense、Xbox、蓝牙、触屏、其他显卡 / DAC / 光驱以及干净 Windows VM、跨显示器与长期连续运行不在本次测试覆盖内。编译成功的结论针对已列开发环境和完整依赖，不对未安装开发组件或未知设备组合作绝对保证。
