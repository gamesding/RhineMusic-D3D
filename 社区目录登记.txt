### 面向用户的说明

- 支持平台：Windows 10 / 11，x64。
- 主要差异（简要）：将 Electron 前端重构为 C++20 / Win32 / Direct3D 11、12 原生界面，保留三维专辑架、玻璃效果、昼夜主题及线性动画；扩展音频处理与输出，支持 WASAPI 共享／独占、ASIO、高解析度及 DSD 播放；支持音频 CD 识别、直接播放与弹出、游戏手柄与触屏操作、单曲／专辑循环，以及中文简繁和拼音搜索。根据显卡能力提供 DLSS／FSR 超分与反射效果；新增独立图形配置程序，提供硬件检测、自动推荐、自定义和软件兼容渲染。
- 运行说明或下载地址：当前衍生版本为 0.1，发行文件统一位于 Release。首次运行建议先打开 RhineConfiguration.exe，确认保存图形设置后，手动双击 RhineMusic.exe；播放器首次使用在音乐库设置中添加音乐目录。运行时无需安装 Electron、浏览器、Node.js 或 Python。也可按仓库 README 安装开发工具并执行 .\build.ps1 自行编译。源码、功能说明、截图与编译步骤：https://github.com/gamesding/RhineMusic-D3D
- 已测试范围与已知限制：已在 Windows x64 环境完成两次干净源码编译、单文件运行校验，以及播放、搜索、循环、滚动、主题、手柄界面与 CD 交互回归；本机显卡、外置 DAC、实体光驱与手柄已有实际测试。其他显卡、DAC、蓝牙连接、真实触屏设备及长期运行尚未全面覆盖。光追、超分、ASIO、原生 DSD 和 DoP 的可用性取决于硬件与驱动，部分设备不支持特定采样率或输出格式。详细验证记录见仓库 docs/SOURCE-BUILD-VALIDATION.md。
- 当前维护状态：持续维护中，当前版本 0.1；由 GamesDing 独立维护本衍生版本，问题与建议请通过本项目 Issues 提交。新增配置程序及图形启动验证见仓库 docs/RELEASE-0.1.md。
